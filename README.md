# Capstone project
This project is the final result of the AI ​​Bootcamp at Slalom.

## Proposal
Create a web tool to plan trips to any destination in the world. The tool offers suggestions for places, excursions, gastronomy, tips, and recommendations for exploring the most attractive and hidden treasures of a city or country within a specific timeframe.

This tool accepts user information about the destination and a basic plan, and allows the user to customize it.

We can provide maps connected to Google Maps or other tools to facilitate access to the plan and share it with other travelers.
